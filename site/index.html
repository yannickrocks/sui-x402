Both sides of the 402

The seller names a price; the payer signs a Sui transaction for exactly that amount; the open-source reference facilitator — self-hosted, unmodified — verifies and settles it before your handler runs.

sell — one paid route (Hono · Express · Next.js)

import { x402 } from "@sui-x402/hono";

app.use("/paid/*", x402({
  payTo: "0xYOUR_SUI_ADDRESS",
  amount: "10000",        // 0.01 USDC, atomic units
  asset: "0xa1ec…7e29::usdc::USDC",
  network: "sui:testnet",
  facilitator: "https://your-facilitator.example",
}));
app.get("/paid/quote", (c) => c.json({ quote: "1.00" }));

pay — a fetch that pays

import { SuiGrpcClient } from "@mysten/sui/grpc";
import { SuiX402Payer, ed25519SignerFromEnv }
  from "@sui-x402/payer-sui";

const payer = new SuiX402Payer({
  client: new SuiGrpcClient({ network: "testnet",
    baseUrl: "https://fullnode.testnet.sui.io:443" }),
  signer: ed25519SignerFromEnv(),  // PAYER_SECRET_KEY
});
const { response, receipt } =
  await payer.fetchWithReceipt("https://api.example/paid/quote");

What one paid request does

Strict mode, the default: settlement is final before a single byte of your content is served. A facilitator outage becomes 503 + Retry-After, never free content.

Offer — 402

The seller answers with PAYMENT-REQUIRED: price in atomic units, the full USDC coin type, payee, network.

Sign

The payer lists its coins, simulates a split + transfer of exactly the amount, checks the simulated balance change itself, and signs — bound to the chain id and current epoch, with a random nonce.

Retry with payment

The same request again, now carrying PAYMENT-SIGNATURE — the signed transaction, base64. The seller relays those bytes untouched.

Verify & settle

The facilitator dry-runs the transaction, checks for replays, broadcasts it, and waits for finality on Sui.

Serve — 200

Only now does the handler run. The response carries PAYMENT-RESPONSE with the on-chain settlement digest.

Testnet, v0.1.0. The live payment loop runs on every push to master. Mainnet is gated behind explicit opt-ins on both sides — sellers need allowMainnet: true, payers must pin the mainnet genesis digest themselves.
